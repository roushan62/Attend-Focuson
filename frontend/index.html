How a site day runs on SiteTrack

1
Company onboards

Signup with GST + OTP-verified mobile → platform owner approves → a private company Sheet, Drive folder and Super Admin are created automatically.

2
Sites get a GPS lock

Drop a map pin per project, set the geofence radius and the marking window. A printed QR code is the indoor fallback.

3
Workers mark in

Live selfie + GPS + device fingerprint. Inside the fence and inside the window = Present. Anything else is Flagged for review — never silently accepted.

4
Accounts gets payroll

Present days, half days, paid leave, overtime and approved expenses combine into a wage sheet. Export Excel or PDF with the site address on every page.

What your team gets
🛰️

Geofence attendance engine

Haversine distance check against the site pin, marking window, late grace and GPS-accuracy limits — validated server-side.

🤳

Live selfie verification

Camera-only capture (no gallery uploads), stored in a private Drive folder per company and served only through token-gated requests.

📵

Offline-first marking

Poor network on site? Entries queue on the phone with GPS + timestamp + selfie and sync later — validated on the captured time.

🔒

Device binding (anti buddy-punching)

One phone per worker. A new device needs admin approval before attendance works again.

🗺️

Live map dashboard

Today's on-site headcount as pins per project, refreshed on load, with flagged marks highlighted.

✅

One approvals centre

Leave, expenses, transfers, flagged attendance, regularization requests and device changes in a single queue.

👷

Sub-vendor manpower

Supervisors log vendor workers by name or bulk headcount; daily/weekly manpower reports follow.

💰

Payroll-ready wage sheet

Payable days + overtime + approved expenses − loss-of-pay days, per employee, ready to hand to accounts.

🧾

Reports & exports

Monthly attendance, employee history, leave/expense summaries, vendor manpower and payroll — Excel, PDF or CSV with the mandatory site address.

📄

Document vault

ID proofs, safety and medical certificates with expiry dates and automatic e-mail reminders before they lapse.

🌐

Hindi / English toggle

The worker app is fully bilingual so site staff can use it without help.

🧮

Complete audit trail

Every approval, edit and export is logged with who/what/when — defensible during payroll disputes.
