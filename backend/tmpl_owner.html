SiteTrack ADMIN PANEL Public site

Administrator key

The admin panel is where company signup requests are approved. It is opened with the OWNER_KEY script property that setupScript() generated — it is not linked from anywhere and no company user can reach it.

Lost the key? Re-run setupScript() in the Apps Script editor to rotate it.

📥 Company signup approvals

A company cannot exist until a request is approved here: approving creates the company spreadsheet (all tabs), the private Drive folder and the Super Admin sign-in, then e-mails the credentials.
